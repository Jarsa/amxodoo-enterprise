This module tweaks the payment method (*Payment Way*) field added by the
Mexican localization to the bank reconciliation views, so the payment
methods cannot be created or edited from there and the column is always
available in the list view. The value set on the statement line is used
to render the CFDI payment complement.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Go to *Accounting > Bank* and open the bank reconciliation widget.
2. Set the *Payment Way* on the bank statement line, either from the
   list view column or from the transaction form view.
