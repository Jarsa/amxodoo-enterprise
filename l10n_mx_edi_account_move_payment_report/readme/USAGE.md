1. Go to an invoice with a payment complement (CFDI tab).
2. Use the *Print* button of the payment document to print the payment
   receipt (also for PUE payments).
3. Use the *Send Payment Receipt* button to send it by email; the receipt of
   a bank transaction is sent with the CFDI XML attached.
4. The *Fiscal Folio* column is available as an optional column in the bank
   reconciliation list view.
