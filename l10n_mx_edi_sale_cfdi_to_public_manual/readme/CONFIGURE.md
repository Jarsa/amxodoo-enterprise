The behaviour can be switched off without uninstalling the module, through
*Settings → Technical → System Parameters*:

- Key: `l10n_mx_edi_sale_cfdi_to_public_manual.disable`
- Value `1` (also `true` or `yes`): standard Odoo behaviour, the checkbox is
  ticked again from the customer fiscal address.
- Value `0` or parameter absent: the checkbox is left to the user.

The change applies immediately, no module upgrade or service restart is
needed.
